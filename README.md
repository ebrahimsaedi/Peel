# 🍎 Peel - Document to TXT Converter

Peel is a lightweight, fast, and fully offline desktop application built with Python and PySide6. It allows you to extract clean, readable text from almost any document format (ebooks, PDFs, Word, Excel, subtitles, and more) and save it as a `.txt` file.

## ✨ Features
- **30+ Formats Supported**: EPUB, AZW3, MOBI, PDF, DOCX, ODT, RTF, Markdown, HTML, PPTX, XLSX, SRT, and more.
- **High Quality Extraction**: Powered by industry-standard tools (Calibre, Pandoc, PyPDF) bundled right inside the app. No external installations required!
- **Drag & Drop**: Simply drop your files into the app.
- **Modern UI**: Supports both Light and Dark themes based on your system settings.
- **100% Offline**: No internet connection is ever needed.

## 📥 Download & Install
You don't need Python or any other software to run this app. Just go to the **Releases** page, download the `Peel-x86_64.AppImage` file, make it executable, and run it!

### 🐧 Note for Fedora Users
If you get an `execv error` when running the AppImage, you can run it using this command:
`./Peel-x86_64.AppImage --appimage-extract-and-run`
